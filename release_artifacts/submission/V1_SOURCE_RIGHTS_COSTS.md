# Source rights, network, and cost

Default execution is `offline`. Public BRREG requests require the explicit
authorized network policy and live-source confirmation flag; protected
endpoints, company websites, and social crawling are excluded. Redirects are
rejected for authorized live runs, physical request starts are bounded, and
telemetry records public endpoint metadata without credentials.

The earlier 100-company public BRREG smoke observed `$0` third-party cost.
That is an observation, not a guarantee for Builderr evaluation. Source terms,
licences, rate limits, and any official evaluator limits must be confirmed
before a live submission run.
